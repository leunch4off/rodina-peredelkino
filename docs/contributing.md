# Development Principles

Every contribution should follow these principles:

- Keep the code simple.
- Write readable code.
- Prefer maintainability over complexity.
- Think about scalability.
- Respect user privacy.
- Prioritize security.
- Follow Apple Human Interface Guidelines whenever possible.

---

# Before You Start

Please check existing:

- Issues
- Discussions
- Pull Requests

Someone may already be working on the same feature.

---

# Pull Requests

Before submitting a Pull Request:

- Test your changes.
- Keep commits meaningful.
- Update documentation when necessary.
- Explain what changed and why.

Small, focused Pull Requests are preferred over very large ones.

---

# Code Style

We aim for consistency across the project.

Please:

- Use descriptive names.
- Keep functions small.
- Avoid unnecessary complexity.
- Prefer SwiftUI best practices.
- Remove unused code before submitting.

---

# Reporting Bugs

When reporting a bug, please include:

- Device
- iOS version
- App version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if possible)

---

# Feature Requests

Feature requests are welcome.

Please explain:

- The problem
- Your proposed solution
- Why it improves the project
