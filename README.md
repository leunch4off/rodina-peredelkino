# 🏙️ Rodina Peredelkino Community

> More than a residential application.
>
> A digital ecosystem where an entire residential complex lives inside one app.

## About

Rodina Peredelkino Community is an independent open-source initiative inspired by ЖК «Родина Переделкино».

The goal is simple but ambitious.

Today, even premium residential complexes require residents to use multiple services every day:

• Messenger chats
• Management company websites
• Smart home applications
• Concierge phone numbers
• Access control applications
• Payment portals
• Paper announcements
• Social media groups

Everything is scattered across different platforms.

Our vision is to unite the entire residential experience into a single mobile application.

A true **City Inside an App.**
